Business Problem

Marriage halls face double bookings, weak advance tracking, and manual billing. Most run on registers or basic desktop tools with no full ERP from booking to settlement.

Solution

Marriage Hall Management Core is phase 1 of the ARMORA Hall ERP suite. Manage venues, halls, and bookings with calendar views and automatic conflict detection, then extend with CRM, rooms, catering, and portal modules.

Phase 1 Features

Venue Master

Marriage hall, banquet, convention, temple hall, and more via configuration.

Hall Inventory

Capacity, AC, parking, dining hall, kitchen, and stage flags per hall.

Booking Management

Muhurtham, reception, engagement, birthday, and corporate events.

Conflict Detection

Block overlapping confirmed bookings on the same hall.

Waitlist and Tentative

Pipeline states before confirmation.

Operations Dashboard

Occupancy, upcoming events, and booking KPIs.

Roadmap Modules

rn_hall_crm, rn_hall_rooms, rn_hall_catering, rn_hall_decoration, rn_hall_vendors, rn_hall_inventory, rn_hall_account, rn_hall_portal, rn_hall_ai, and mobile API.

Hall Core → CRM → Payments → Catering → Portal → Full ERP

Installation

  1. Install Marriage Hall Management Core from Apps.
  2. Open Marriage Hall > Configuration > Hall Settings.
  3. Create venue and hall records.
  4. Start bookings from the calendar view.
