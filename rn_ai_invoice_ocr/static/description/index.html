Overview

Documents, IDP, and attachment workflows in Odoo

Turn supplier invoice PDFs and images into draft vendor bills with review.

AI Invoice OCR Drag-and-drop upload (PDF, JPG, PNG, multi-page PDF) It is built for Odoo 19 Community by ARMORA IT Technologies.

The Problem

  • Documents sit in email and shared drives
  • Extraction and filing are manual
  • Hard to open related files from a business record
  • No dashboard for pending document work
  • Access rights for confidential files are messy

The Solution

  • Document workflows in Odoo
  • Smart buttons to related attachments/docs
  • IDP helpers where the module provides them
  • Operations dashboard for pending work
  • Security groups for document access

Installation

  1. Add rn_ai_invoice_ocr to your addons path
  2. Restart the Odoo service
  3. Apps → Update Apps List
  4. Search AI Invoice OCR
  5. Click Install
  6. Complete settings and use the Files smart workflows
