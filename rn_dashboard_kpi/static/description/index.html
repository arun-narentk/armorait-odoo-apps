Dashboard KPI Studio

No-code Odoo 19 dashboard builder by ARMORA IT Technologies.

Overview

Build KPI tiles, charts, and interactive layouts from any Odoo model the user can access. Phase 1 ships the installable foundation. Visualization, data engine, and commercial features follow in later releases.

Compatibility

  • Odoo 19 Community
  • Python 3.12
  • OWL 2 + Chart.js (Odoo web.chartjs_lib)
