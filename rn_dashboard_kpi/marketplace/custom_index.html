Overview

No-code KPI boards for Odoo 19 Community

Dashboard KPI Studio lets managers and power users configure dashboards, items, and filters in the backend, then open a dedicated client action. Aggregations always run with the signed-in user rights.

The Problem

  • Spreadsheets drift away from live Odoo data
  • Custom dashboards need developer time for every KPI
  • Shared boards often ignore access rights
  • Hard to reuse layouts across companies

The Solution

  • Configure tiles and charts from any model
  • Share by owner, group, or public flag
  • Secure ORM count and grouped aggregations
  • Export portable JSON definitions

Key Features

Dashboard Builder

Create boards with theme, layout, refresh, and company scope.

KPI Items

Tiles, charts, and lists with domain, measures, and aggregation.

Filters and Bookmarks

Shared board filters plus personal favorites per user.

Secure Data Engine

Aggregations use the current user environment only.

Sharing Controls

Owner, allowed groups, or share with all internal users.

JSON Export

Download a portable definition for backup or transfer.

Installation

  1. Add rn_dashboard_kpi to your addons path
  2. Restart the Odoo service
  3. Apps → Update Apps List
  4. Search Dashboard KPI Studio
  5. Click Install
  6. Assign User or Manager rights
