Installation

  1. Download the module ZIP from the Odoo Apps Store
  2. Extract rn_textile_base into your custom addons path
  3. Restart Odoo and update the Apps list
  4. Install Textile Manufacturing Core
  5. Complete settings and assign security groups
  6. Optional: load demo data for evaluation
