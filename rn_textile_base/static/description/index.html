Business Problem

Knitting, dyeing, and garment units still split production, inventory, costing, and exports across Excel, Tally, and legacy tools. Integration is the gap.

Solution

Textile Manufacturing Core is phase 1 of the ARMORA Textile ERP suite. Register plants, departments, machines, and yarn specs, then extend with dyeing, knitting output, job work, MRP, quality, and export modules.

Phase 1 Features

Factory Master

Spinning, knitting, dyeing, garment, export, and trader unit types.

Departments

Knitting, dyeing, cutting, stitching, QC, warehouse, and more.

Machine Registry

Knitters, looms, stenters, boilers, compressors with capacity and state.

Yarn Specifications

Count, blend, GSM, color, lot prefix for batch traceability hooks.

Utilization Dashboard

Active machines, breakdown alerts, plant KPI shell.

Enterprise Settings

Job work, lot traceability, export docs, piece-rate flags.

Roadmap Modules

rn_textile_yarn, rn_textile_dyeing, rn_textile_knitting, rn_textile_jobwork, rn_textile_mrp, rn_textile_quality, rn_textile_export, rn_textile_energy, rn_textile_ai, and more.

Plant Core → Yarn and Inventory → Production → Quality → Export → Full ERP

Installation

  1. Install Textile Manufacturing Core from Apps.
  2. Open Textile > Configuration > Textile Settings.
  3. Create factory, departments, machines, and yarn specifications.
  4. Assign Shop Floor, Supervisor, or Plant Manager groups.
