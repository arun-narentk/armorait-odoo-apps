Installation Details

  1. Copy the module into your custom addons path.
  2. Restart Odoo and update the Apps list.
  3. Install Textile Manufacturing Core (technical name: rn_textile_base).
  4. Open Settings and complete module configuration.
  5. Assign security groups to users.
  6. Optional: load demo data for evaluation.
