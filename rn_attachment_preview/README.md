# Attachment Preview

Preview PDFs, images, videos, audio, and text files directly inside Odoo without downloading them.

## Features

- Visual thumbnail strip on attachment widgets
- Hover preview for images and lightweight files
- Full-screen gallery viewer
- PDF, image, video, audio, and text support
- Secure preview respecting Odoo ACLs
