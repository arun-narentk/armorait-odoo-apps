WHATSAPP ODOO INTEGRATION

By ARMORAIT

WhatsApp is a hugely popular messaging platform used by billions worldwide. This app enables users to send messages from Odoo via WhatsApp for one-on-one communication. Messages can be sent from Sale Orders, Purchase Orders, Invoicing, and Delivery Order details. One click opens WhatsApp with the contact's number and a pre-filled message including document reference, amount, and line items — with optional secure PDF links. No API or WhatsApp Business account required; works with wa.me.

SCREENSHOTS

Update WhatsApp number of the customer in the Contacts app

To send a WhatsApp message, add or update the contact's Phone or Mobile number in the Contact form (with country code, e.g. 919731100987).

Send via WhatsApp from Invoice

On a posted customer invoice, click Send via WhatsApp in the header (next to Print). WhatsApp opens with the customer's number and a pre-filled message including invoice reference, amount, due date, line items, and a secure PDF download link.

Structured message and document link

The message includes document reference, total amount, line items (product, quantity, amount), and an optional link to view or download the PDF.

Sale Order, Purchase Order & Delivery Order

The same Send via WhatsApp button appears on Sale Orders (quotations and confirmed orders), Purchase Orders, and Delivery/Transfer forms. Each opens WhatsApp with a pre-filled message tailored to the document (order ref, amount, items; delivery ref, contact, product lines).

USER GUIDE

WhatsApp Odoo Integration — Installation & Configuration

Requirements: Odoo 19 with Sales, Purchase, Invoicing (Accounting), and Inventory apps installed.

Installation: Install the module from Apps. Update the Apps list if needed, then search for "WhatsApp Odoo Integration" and click Install.

Configuration: Ensure contacts (customers, vendors, delivery contacts) have Phone or Mobile set with country code (e.g. 919731100987). For document links in messages to work, set web.base.url correctly in System Parameters.

Usage: Open a Sale Order, Purchase Order, Invoice, or Delivery Order. Click Send via WhatsApp in the form header. WhatsApp opens in a new tab with the contact's number and a pre-filled message; send the message (and optional PDF link) to your contact.
