Overview

One Odoo-native platform for process orchestration across sales, purchase, inventory, HR, CRM, and accounting

Most teams stitch automations across spreadsheets, chat bots, and brittle custom code. When an approval fails or a webhook times out, nobody has a single place to see what ran, what stopped, and what to retry.

ARMORA AI Automation Platform puts visual workflows, AI-assisted building, approval steps, incoming and outgoing webhooks, execution logs, and a connector-ready architecture inside Odoo 19 Community. Install starter workflows, adapt them to your process, and monitor every run from the dashboard.

The Problem

  • Automations live in disconnected tools outside Odoo
  • No clear visual map of who approves what, when
  • Failed jobs vanish without a retry queue or timeline
  • Hard to reuse the same pattern across sales, purchase, and HR
  • External Zapier-style stacks add cost and data risk

The Solution

  • Visual workflows for triggers, conditions, and actions
  • AI builder to draft and validate automations faster
  • Approvals baked into the same execution path
  • Webhooks in and out, with retries and error logs
  • Starter templates for common Odoo processes

Key Features

Built for operations, finance, and technical leads who want automation inside Odoo

Visual Workflow Builder

Model triggers, validation, approvals, execute steps, and notifications in a clear Odoo-native flow.

AI Workflow Generation

Describe the process in plain language. The AI builder drafts structure you can review and refine.

Approval Integration

Route managers through the same run path so approvals stay auditable with the automation.

Webhooks In & Out

Accept incoming events and push outgoing calls. Retry failed jobs and inspect error logs.

Smart Connectors

Connector-ready design for OCR, WhatsApp, IoT, MES, and REST integrations as you grow.

Execution Dashboard

Track open, in-progress, completed, and alerted runs. Open the timeline when something fails.

How It Works

1
Install the platform
Add rn_workflow_builder, update Apps, and install. Starter workflows load with the module.
2
Pick or design a workflow
Use a starter (sales approval, reorder, leave, welcome mail) or build from the visual designer / AI wizard.
3
Configure triggers and approvals
Bind Odoo events or schedules, set conditions, and assign approval groups where needed.
4
Connect webhooks and actions
Call Odoo actions, notify Discuss users, or hit external endpoints through smart connectors.
5
Monitor and retry
Use the dashboard and execution log to watch KPIs, open failures, and retry safely.

Installation

  1. Add rn_workflow_builder to your addons path
  2. Restart the Odoo service
  3. Apps → Update Apps List
  4. Search AI Automation Platform
  5. Click Install
  6. Open the app menu and activate a starter workflow

Technical Notes

  • Technical name: rn_workflow_builder
  • Depends on: base, mail, web, sale, purchase, account, hr, stock, crm, and related apps
  • UI: OWL 2 designer and dashboard assets
  • Compatible: Odoo 19 Community
