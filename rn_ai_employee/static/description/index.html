AI Copilot for Odoo

The enterprise intelligence layer for your ERP

AI Copilot for Odoo 19 is not a chatbot add-on. It is an operating layer above Odoo that lets your team ask, reason, act, and automate across sales, finance, inventory, CRM, and purchase. Session memory, write confirmation, audit logs, and proactive morning briefings are built in for enterprise use.

How It Works

  1. Install AI Copilot for Odoo (technical name: rn_ai_employee)
  2. Go to AI Copilot > Settings and enable the platform
  3. Configure LLM provider, confirmation, and optional morning briefing
  4. Assign AI Copilot User or Manager groups to your team
  5. Open the systray icon or Ask AI Copilot from the menu
  6. Ask a question, confirm write actions when prompted, review the audit log

FAQ

Is this just a chatbot?
No. AI Copilot is an enterprise operating layer: skills, memory, confirmation, audit, and proactive briefings over live Odoo data.

Does it work on Odoo Community?
Yes. Built and tested for Odoo 19 Community. Also works on Enterprise and Odoo.sh.

How are write actions protected?
Write skills require explicit confirmation by default. Every execution is logged in the audit trail with user, tool, and result.

Do I need an OpenAI API key?
No. Rule-based routing works without a key. Add a key to enable LLM routing for broader natural-language questions.
