AI Chatbot

Ask Odoo anything. Get answers from live business data.

AI Copilot for Odoo 19. Managers ask plain-language questions on sales, accounting, inventory, and CRM. The intent engine calls registered tools and returns answers with optional action cards to open lists or create follow-ups.

Key Benefits

  • Plain-language questions on real company data
  • Built-in analytics for sales, accounting, inventory, and CRM
  • Suggested questions so managers start fast
  • Action cards: Open List and Create Activity
  • Permission-aware tools and full conversation history
  • Works on Community, Enterprise, and Odoo.sh

Features

Intent Engine

Maps questions like "Show overdue invoices" or "Why did revenue drop?" to the right Odoo tool.

Tool Registry

20+ read-only helpers across sales orders, invoices, stock, and CRM leads.

Copilot Chat

Conversation view with suggested questions, draft input, and assistant replies.

Action Cards

Jump to filtered lists or schedule activities without leaving the chat.

Provider Settings

Configure OpenAI or compatible API endpoints from Odoo Settings.

Security Groups

Separate user and manager roles with access rules on chats and tools.

How It Works

  1. Install AI Chatbot from Apps (technical name: rn_ai_employee)
  2. Go to AI Copilot > Settings and enable the copilot
  3. Enter your AI provider API key and model name
  4. Assign AI Copilot User or Manager groups to your team
  5. Open Ask Copilot and try a suggested question
  6. Review the answer and run an action card if needed

FAQ

Does it work on Odoo Community?
Yes. Built and tested for Odoo 19 Community. Also works on Enterprise and Odoo.sh.

Does it change data automatically?
Phase 1 focuses on read-only analytics. Action cards open lists or create activities with user confirmation.

Can I add custom tools?
Yes. Extend the tool registry using standard Odoo inheritance patterns.
