AI Employee

Ask Odoo anything. Get answers and actions from live business data.

AI Employee for Odoo 19. Managers ask plain-language questions on sales, accounting, inventory, and CRM. The assistant routes each question to registered tools, returns clear answers, and offers action cards to open records, schedule follow-ups, or run guided write actions such as quotations and payment reminders.

How It Works

  1. Install AI Employee from Apps (technical name: rn_ai_employee)
  2. Go to AI Employee > Settings and enable the assistant
  3. Enter your AI provider API key and model name (optional but recommended)
  4. Assign AI Employee User or Manager groups to your team
  5. Open the chat icon in the top bar or use Ask AI Employee from the menu
  6. Try a suggested question or ask in your own words
  7. Review the answer and run an action card if needed

FAQ

Does it work on Odoo Community?
Yes. Built and tested for Odoo 19 Community. Also works on Enterprise and Odoo.sh.

Does it change data automatically?
Analytics tools are read-only. Guided write tools such as create quotation and send payment reminders run only when you ask for them in chat. Action cards still require your confirmation before opening records or scheduling activities.

Do I need an OpenAI API key?
No. Rule-based routing works without a key. Add a key to enable LLM routing for broader natural-language questions.

Can I add custom tools?
Yes. Extend the tool registry using standard Odoo inheritance patterns.
