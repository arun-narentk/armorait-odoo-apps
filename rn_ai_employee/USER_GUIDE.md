# User Guide

        ## AI Chatbot

        AI Chatbot is an Odoo-native copilot that understands intent, calls registered tools, and returns answers with optional actions on CRM, sales, stock, and accounting.

        ## Typical workflow
        1. Install copilot
2. Set API key
3. Open chat
4. Ask a question
5. Review action
6. Confirm in Odoo

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
