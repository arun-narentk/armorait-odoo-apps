The Problem

  • Teams handle employee self-service for payslips, leave, and hr documents with spreadsheets or disconnected tools
  • No clear place in Odoo for daily status and follow-up
  • Approvals and visibility stay inconsistent across users
  • Hard to scale the same process across companies
  • Upgrade-safe documented apps are hard to find

The Solution

  • Dedicated Odoo app for Employee self-service for payslips, leave, and HR documents
  • Native forms, lists, dashboards, and settings
  • Security groups and access rights included
  • Built for Odoo 19 Community and multi-company use
  • Support from ARMORA IT Technologies

Installation

  1. Download the module ZIP from the Odoo Apps Store
  2. Extract rn_payroll_portal_pro into your custom addons path
  3. Restart Odoo and update the Apps list
  4. Install Payroll Portal
  5. Complete settings and assign security groups
