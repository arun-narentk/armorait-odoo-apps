Overview

Projects, sites, and construction ops tracked in Odoo

Flagship vertical for contractors, builders, and infrastructure firms.

Construction ERP Core Construction projects, sites, phases, milestones Built for Odoo 19 Community by ARMORA IT Technologies.

The Problem

  • Site progress is updated in WhatsApp and sheets
  • Related POs and bills are hard to open from the project
  • Material and labor status are disconnected
  • Managers lack one dashboard for delays
  • Multi-site companies need consistent process

The Solution

  • Construction projects in Odoo
  • Smart buttons to related purchase and bills
  • Site status on the project
  • Operations dashboard for open tasks
  • Security for project roles

Installation

  1. Add rn_construction_core to your addons path
  2. Restart the Odoo service
  3. Apps → Update Apps List
  4. Search Construction ERP Core
  5. Click Install
  6. Complete settings and use the POs workflows
