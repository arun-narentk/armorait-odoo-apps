# User Guide

        ## Credit Control

        Credit Control scores partner risk, enforces limits, blocks risky orders, and automates WhatsApp payment reminders.

        ## Typical workflow
        1. Set credit limit
2. Score on order
3. Block or approve
4. Send reminder
5. Collect payment

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
