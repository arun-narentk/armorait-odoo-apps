Messaging Bot Engine

Omnichannel inbox, connectors, and bot flows for customer chat

Connect WhatsApp and more to Odoo. Route inbound messages to a unified inbox, run menu-based bot flows, create CRM leads from chat, and hand off to agents.

Key Benefits

  • Unified inbox for customer conversations across channels
  • Bot flows with menus, messages, CRM actions, and human handoff
  • WhatsApp Cloud API webhook intake with simulation mode for testing
  • Auto-create CRM leads from qualified chat sessions
  • Multi-company security with user, admin, and technical groups
  • Production-ready service layer for connectors and bot engine

Features

Connectors

Register WhatsApp, Instagram, Facebook Messenger, and live chat connectors per company.

Bot Engine

Build flows with message nodes, menus, CRM actions, and agent handoff steps.

Inbox

Track inbound and outbound messages, partners, and conversation state in one place.

Webhooks

Public webhook endpoint with token verification for provider callbacks.

Simulation Mode

Test flows locally without calling external messaging APIs.

CRM Integration

Create leads from bot actions and link them to the conversation thread.

How It Works

  1. Install Messaging Bot Engine (technical name: rn_messaging_bot)
  2. Create a connector and assign the demo Support Assistant bot
  3. Enable simulation mode or add WhatsApp Cloud API credentials
  4. Configure the webhook URL in your provider dashboard
  5. Send a test message and review the inbox thread
  6. Customize bot nodes or hand off to a human agent when needed
