# User Guide

        ## Profit Guard

        Profit Guard blocks or warns on low-margin order lines and highlights slow and dead inventory with clearance suggestions.

        ## Typical workflow
        1. Set thresholds
2. Confirm sales order
3. Review margin alert
4. Manager override
5. Act on dead stock

        ## Tips
        - Start with demo data to learn the screens.
        - Configure settings before inviting end users.
        - Use dashboards for daily operations reviews.
