Vertical ERP foundation for temples, trusts, ashrams, gurudwaras, churches, and religious institutions

Business Problem

Medium and large temples still run on paper registers, Excel, and disconnected software. Generic ERP products do not model trust governance, festival calendars, and branch operations in one Odoo-native platform.

Solution

Temple Management Core is phase 1 of the ARMORA Temple ERP suite. Configure institution type once, then extend with devotee CRM, donations, seva booking, annadhanam, and portal modules.

Phase 1 Features

Temple Master

Trust details, registration, deity focus, and official contact.

Branches

Multi-shrine and multi-location management with head office flag.

Trustees and Priests

Governance roles and ritual staff linked to branches.

Daily Timings

Morning, evening, and special darshan schedules by day.

Festival Calendar

Plan utsavams with budget estimates and workflow states.

Operations Dashboard

KPI cards and upcoming festivals for trust managers.

Installation

  1. Install Temple Management Core from Apps.
  2. Open Temple > Configuration > Temple Settings.
  3. Create your temple master and branches.
  4. Assign Counter, Office, or Trust Manager groups to users.

Compatibility

  • Odoo 19 Community
  • Python 3.12
  • PostgreSQL
  • Depends: base, mail, web, contacts, calendar, portal, hr
